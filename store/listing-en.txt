Give a web AI hands on your computer.

Chat with DeepSeek or Muse and tell it what you want done on your own machine.
When the AI needs to act, it writes a command block; webai-claw runs the command
through a local host and returns the result to the same chat.

No API keys. No copy-pasting. No developer-operated relay server.

SUPPORTED AI CHATS
- DeepSeek: chat.deepseek.com
- Muse: muse.ai

WHAT IT DOES
- Run shell commands on macOS or Windows from a web AI chat.
- Return stdout, stderr, and exit status to the conversation.
- Upload local files as real chat attachments.
- Drive local applications such as Blender through their local APIs.
- Keep the target explicit when the same chat is open on more than one
  computer.

HOW IT WORKS
This extension is the browser half of webai-claw. It needs the free, open-source
local host installed on each machine that will run commands:

1. Install this extension.
2. Install the local host from the project page:
   github.com/Achillesy/Python-webai-claw
3. Open a supported AI chat and click Connect in the extension popup.

The local host communicates with the extension through Chrome Native Messaging.
It does not listen on a network port.

PRIVACY AND SECURITY
- The developer does not collect analytics, advertising data, or personal data.
- The host does not prompt for, store, or fill passwords. Never put passwords in commands.
- Sensitive paths such as SSH keys, browser cookies, and .env files are refused
  for file uploads; a single upload is capped at 25 MB.
- Command output and uploaded files still go to the AI site you choose. Review
  sensitive content before sending it.
- Privacy policy: github.com/Achillesy/Python-webai-claw/blob/master/PRIVACY.md
