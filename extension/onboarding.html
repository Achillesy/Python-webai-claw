Step 1 — Install the local helper

Copy the line for your system, paste it into a terminal, press Enter. No admin rights needed.

macOS

curl -fsSL https://raw.githubusercontent.com/Achillesy/Python-webai-claw/master/native-host/install.py | python3

Windows (PowerShell)

py -3 -c "import urllib.request; exec(urllib.request.urlopen('https://raw.githubusercontent.com/Achillesy/Python-webai-claw/master/native-host/install.py').read())"

You run this command in your own terminal. The extension does not download or execute remote code. It installs the helper into ~/.webai-claw/, puts the skill library in ~/webai-claw-skills/, and registers it with Chrome and Edge. Add custom skills under custom/.

Step 2 — Connect in the AI chat

Your machine ID (the host value for command blocks):

Open muse.ai or chat.deepseek.com, click the webai-claw toolbar icon, then click Connect.

The extension attaches AI-AGENT.md and the local config automatically. A visible skill library is in ~/webai-claw-skills/. For Blender tasks, ask the AI to use the Blender skill; it reads AI-BLENDER.md automatically.
